Objective

This project performs customer segmentation using Machine Learning (K-Means Clustering) to identify different groups of customers based on their behavior and spending patterns.

📊 Dataset
File: customer_segmentation_data.csv
Contains customer-related features such as spending behavior and purchase patterns.
🧠 Methodology
Data loading and preprocessing
Exploratory Data Analysis (EDA)
Feature selection
Finding optimal clusters using Elbow Method
Applying K-Means Clustering
Visualizing customer segments
📈 Visualizations
🔹 Elbow Method

Used to determine the optimal number of clusters.

🔹 Customer Segmentation Clusters

Shows how customers are grouped into different segments.

🔹 Final Visualization

Final representation of clustered customer groups.

📌 Key Insights
Customers are divided into distinct behavioral groups
Each cluster represents different spending patterns
Can be used for targeted marketing strategies

Example:

High-value customers → premium offers
Low-spending customers → retention campaigns
